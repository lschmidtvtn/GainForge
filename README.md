# GainForge

GainForge enables real-time, data-driven decision-making through distributed-transaction-processing and auto-recovery-mechanism for optimized system manager.

GainForge is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/GainForge.git`
2. `cd GainForge`
3. Install in editable mode: `pip install -e .`

## Configuration

GainForge is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
